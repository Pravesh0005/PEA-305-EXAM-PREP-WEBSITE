## 💡 High-Yield Formulas

> Memorize these 15 formulas and solve 80% of aptitude questions

```
📊 AVERAGE
   Avg of AP = Middle term
   Replacement: New avg = Old avg + (New-Old)/n
   Wrong entry: Students = Diff/Change in avg

💯 PERCENTAGE
   Successive: Net% = a + b + ab/100
   A x% more → B less by: x/(100+x) × 100%
   Price ↑r% → Reduce: r/(100+r) × 100%
   x% of y = y% of x  (SWAP TRICK!)

💰 PROFIT & LOSS
   Same SP x% each → Loss = x²/100 %
   Faulty weight: (True-False)/False × 100%
   Buy n get k free → Discount = k/(n+k) × 100%

📐 HCF & LCM
   HCF × LCM = Product (for two numbers)
   Trailing zeros n! = ⌊n/5⌋ + ⌊n/25⌋ + ⌊n/125⌋
   Total factors = (p+1)(q+1)... for A^p × B^q...
```

## ⚠️ Critical Traps

```diff
# PERCENTAGE TRAPS:
- ❌ A is 20% more than B → B is 20% less than A
+ ✅ B is 16.67% less (= 20/(100+20)×100)

- ❌ +20% then -10% = 10% increase
+ ✅ Net = 20 + (-10) + (20×-10)/100 = 8% increase

# PROFIT-LOSS TRAPS:
- ❌ Same SP, 20% profit AND 20% loss → no loss
+ ✅ ALWAYS a LOSS = 20²/100 = 4% loss

- ❌ Faulty weight: profit = (True-False)/True × 100
+ ✅ Profit = (True-False)/FALSE × 100 (divide by FALSE!)

# AVERAGE TRAPS:
- ❌ Average two groups = avg of their averages
+ ✅ Weighted average = (n1×a1 + n2×a2)/(n1+n2)

# CODING TRAPS:
- ❌ In substitution: "Red is called Yellow" → answer is Red
+ ✅ Answer is Yellow (what it IS CALLED in that language)

# HCF/LCM TRAPS:
- ❌ "Greatest number dividing a,b,c same remainder" = HCF(a,b,c)
+ ✅ = HCF of DIFFERENCES (a-b, b-c, a-c)

# NUMBER SYSTEM TRAPS:
- ❌ Divisible by 6 = divisible by 2 OR 3
+ ✅ Divisible by 6 = divisible by 2 AND 3 BOTH
```

## 🎯 Exam Strategy

```
⏱ TIME MANAGEMENT (Critical for aptitude):

   Vedic Maths Qs  → 20-30 seconds each (use shortcuts!)
   Average Qs      → 30-45 seconds
   Percentage Qs   → 30-60 seconds (use fraction table)
   Profit-Loss Qs  → 45-90 seconds
   Series Qs       → 15-30 seconds (pattern recognition)
   Coding Qs       → 20-40 seconds
   HCF/LCM Qs     → 30-60 seconds

🎯 PRIORITY ORDER:
   1. Series & Coding (fastest, pattern-based)
   2. Vedic Maths (speed with shortcuts)
   3. Average (formula-based, quick)
   4. Percentage (fraction conversion key)
   5. Profit-Loss (careful with same-SP trap)
   6. HCF/LCM (need careful computation)

🧮 KEY MENTAL MODELS:
   Always ask: "Can I use a fraction instead of %?"
   Always ask: "Is this the same-SP trap?"
   Always ask: "What's the pattern in this series?"
   Always ask: "What words appear in multiple sentences?" (coding)
```
